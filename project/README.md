# IR NDA APP by PRATIK v1.2.8

Offline Railway Night Duty Allowance calculator with PDF, monthly history, weekly duty pattern, backup/restore, dashboard, multilingual UI, dark mode, AI/voice duty assistant and offline device-bound licensing.

## Offline licensing
- No server, Firebase or login required.
- First activation uses the device's Android ID.
- License key is generated for a specific Device ID.
- Validity options: 7 days, 30 days, 90 days, 180 days, 1 year and Lifetime.
- Same key can be entered again after reinstall on the same device (subject to Android ID remaining the same).
- Same key is rejected on a different device.
- The app stores the last known date to provide basic clock-rollback protection.
- Keep `IR_NDA_LICENSE_GENERATOR.html` private.
